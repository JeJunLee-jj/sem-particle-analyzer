# SEM 입자 분석기

전자현미경(SEM) 사진에서 입자를 자동으로 찾아 형상 지표를 재고, EDS 조성과 합쳐
"어떤 형상이 어떤 원소로 이루어져 있는지"를 보는 웹 도구입니다.
서버 없이 **브라우저 안에서만** 동작하며, 올린 사진은 기기 밖으로 나가지 않습니다.

지하철 미세먼지 발생원 분류 연구를 위해 만들었고, 분류 규칙은 두 개의 프로토타입
스크립트(조성 규칙 v1/v2, 형상 규칙)를 합성 데이터로 점검한 결과를 그대로 옮긴 것입니다.

## 바로 써보기

**https://jejunlee-jj.github.io/sem-particle-analyzer/**

설치도 압축 풀기도 필요 없습니다. 합성 예제 이미지가 이미 분석된 상태로 뜹니다.

로컬 파일로 쓰시려면 `docs/index.html`을 브라우저로 열면 됩니다. 단, **파일 네 개가
같은 폴더에 있어야 합니다** — `index.html`, `ip.js`, `accum.js`, `example-sem.png`.

> 압축 파일을 풀지 않고 탐색기의 압축 폴더 보기에서 `index.html`만 더블클릭하면
> 윈도우가 그 파일 하나만 임시 폴더로 꺼내 열기 때문에 분석이 동작하지 않습니다.
> 반드시 압축을 먼저 전부 푸세요. (이 경우 페이지가 무엇이 빠졌는지 알려줍니다.)

GitHub Pages로 공개하려면 저장소 설정에서 **Settings → Pages → Source: `main` 브랜치의
`/docs` 폴더**를 선택하세요. 빌드 과정이 없습니다.

로컬에서 서버로 띄울 때는 **문자 인코딩에 주의하세요.** `python -m http.server`는
`charset`을 붙이지 않아 한글이 깨집니다. 파일을 직접 열거나(`file://`), charset을
붙여주는 서버를 쓰세요.

```bash
npx serve docs
```

## 기능

### 1. 형상 — SEM 이미지

사진을 올리면 그레이스케일 → 가우시안 블러 → Otsu 이진화 → 구멍 채우기 →
연결성분 라벨링 → 접촉 입자 분할 → 형상 지표 계산까지 한 번에 돕니다.

- **스케일 보정**: 이미지 위에 스케일바를 긋고 실제 길이를 입력하면 모든 값이 µm로 나옵니다.
  보정 전에는 px로 표시하고 "미보정"을 명시합니다.
- **하단 정보바 제외**: 배율·가속전압이 찍힌 띠를 입자로 잡지 않도록 잘라냅니다.
- **접촉 분리**: 거리변환 + 마커 watershed로 맞닿은 입자를 나눕니다. 강도 조절 가능.
- 입자를 클릭하면 등가원 지름·최대 Feret·원형도·고형도·종횡비가 열립니다.

### 2. 조성 — EDS

세 가지 경로로 조성을 넣습니다.

| 경로 | 무엇이 되나 |
|---|---|
| **원소 맵 이미지** | 검출된 **모든 입자**에 조성이 자동으로 붙습니다 (세기 기반 반정량) |
| **정량표 붙여넣기** | 세로형·가로형 표를 모두 읽습니다. 입자에 직접 연결 |
| **EDS 화면 사진** | 사진을 띄워놓고 값을 직접 입력하거나 수정 |

> SEM 사진 자체에는 원소 정보가 없습니다. 원소는 X선 스펙트럼에서만 나오므로
> EDS 결과를 함께 넣어야 조성 분석이 됩니다.

**정량 기준**을 금속기준(C·O 제외)과 전체기준 사이에서 바꿀 수 있습니다.
같은 스펙트럼도 어느 쪽으로 정규화했는지에 따라 Fe 값이 30%p 이상 벌어지므로,
임계값은 반드시 기준과 함께 기록해야 합니다.

### 3. 통합 결과

입자 하나가 한 줄입니다 — 형상 분류, 크기, 형상 지표, 원소별 wt%, 조성 판정.
아래의 **형상 × 조성 교차 막대**가 본론으로, 발생원마다 형상이 다른지 확인하는 자리입니다.

### 4. 누적 데이터

시야(사진) 하나를 통째로 저장해 여러 장을 하나의 데이터셋으로 모읍니다.

- 시야별 목록, 합산 크기 분포, **시야별 형상 분포 비교**(재현성 확인)
- 전체 합산 형상 × 조성 교차
- **임계값 재보정**: 쌓인 실제 입자들의 분포에서 골이 파이는 자리(Otsu)를 찾아
  종횡비·고형도·원형도 경계를 제안합니다. 기본값은 합성 데이터에서 나온 값이므로
  실제 시료에 맞게 다시 잡는 것이 맞습니다.
- **형상 군집(k-평균)**: 규칙을 걷어내고 원형도·고형도·종횡비만으로 입자를 묶습니다.
  한 군집 안에 규칙 분류가 여러 개 섞여 있다면 그 경계에서 규칙이 데이터를
  실제 모양대로 가르지 못하고 있다는 뜻입니다.
- 누적 CSV 내보내기 / 불러와 합치기 (기기·팀원 간 데이터 병합)

데이터는 브라우저(`localStorage`)에 저장됩니다. 캐시를 지우면 사라지므로
중요한 데이터는 CSV로 내보내 두세요.

## 지표 정의

| 지표 | 정의 |
|---|---|
| 등가원 지름 | 2·√(면적/π) |
| 최대 Feret | 볼록 껍질 위 두 점 사이의 최대 거리 |
| 둘레 | 윤곽 추적 길이(직교 1, 대각 √2) × 0.95 (디지털 곡선 보정) |
| 원형도 | 4π·면적 / 둘레². 완전한 원이 1 |
| 고형도 | 면적 / 볼록 껍질 면적 |
| 종횡비 | 2차 모멘트로 구한 장축/단축 비 |

## 형상 분류 규칙

순서대로 적용합니다. 임계값은 모두 조절할 수 있습니다.

1. 종횡비 ≥ 2.80 → **침상**
2. 고형도 < 0.72 → **응집형**
3. 원형도 ≥ 0.80 그리고 종횡비 < 1.30 → **구형**
4. 나머지 → **불규칙**

## 조성 분류 규칙

**v1 (단일원소)**: Fe·Al·Ti 중 40% 이상인 것으로 판정. 전체기준에서는 Al이 임계에
도달하지 못해 토양·광물 입자가 통째로 미분류로 빠지는 약점이 있습니다.

**v2 (계층형)**: C ≥ 55% → 탄소질 / Fe ≥ 40% 그리고 Si+Al < 30% → Fe-rich /
Ti ≥ 40% → Ti-rich / Si+Al ≥ 50% 그리고 0.15 ≤ Al/Si ≤ 1.2 → 알루미노실리케이트 /
Ca ≥ 40% → Ca-rich / Fe ≥ 20% 그리고 Si+Al ≥ 25% → Fe-광물 혼합 / 그 외 → 기타

## 한계

- **원소 맵 조성은 반정량입니다.** 맵 세기가 농도에 비례한다고 본 값이라 ZAF 보정과
  표준시료를 거친 정량값이 아닙니다. 수치 자체보다 입자 간 상대 비교에 쓰세요.
- **접촉 입자 분할은 완전하지 않습니다.** 심하게 겹친 입자는 여전히 하나로 잡힙니다.
- **배율이 다른 시야를 섞지 마세요.** 스케일을 보정하지 않은 시야가 섞이면 크기
  분포가 왜곡됩니다. 페이지가 경고를 띄우지만, 애초에 시야마다 보정하는 것이 맞습니다.
- 임계값은 합성 데이터에서 나온 기본값입니다. 실측 데이터로 재보정해야 합니다.

## claude.ai 판과의 차이

이 도구는 claude.ai 아티팩트로도 게시되어 있습니다. 그쪽에서는 두 기능이 더 동작합니다.

- **EDS 정량표 사진 읽기**: Claude가 사진 속 표를 읽어 옮깁니다.
- **기록용 요약 초안**: 측정 수치를 넘겨 실험 노트용 문단을 받습니다.

두 기능 모두 claude.ai 런타임이 필요하므로 GitHub Pages에서는 빠지고,
대신 값을 직접 입력하는 편집기로 대체됩니다. 나머지 기능은 동일합니다.
